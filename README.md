# LN Cars Valjevo

Demo sajt za auto plac LN Cars, Beogradski put bb, Valjevo.

Sajt: https://cheef30.github.io/ln-cars-valjevo/

Čist HTML, CSS i vanilla JS, bez build koraka. Hostuje se na GitHub Pages sa `main` grane.

- `index.html` početna
- `vozila/audi-q3-2018.html` stranica vozila, uzor za buduća vozila
- `assets/css/style.css`, `assets/js/main.js`

Fotografije vozila i placa su hotlinkovane iz oglasa LN Cars na eAuto.rs i Polovnim automobilima.
